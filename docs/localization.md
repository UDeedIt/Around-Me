# Localization in Around Me

This document describes how localization is implemented in the Around Me Flutter app.
The goal is to keep all user-facing text translatable and maintainable, while avoiding
hardcoded strings in the UI code.

---

## Overview

Around Me uses Flutter’s built-in localization system (flutter_localizations) and the
gen-l10n tool with ARB files. All user-facing strings are defined in .arb files under
lib/l10n/, and Dart code accesses them through the generated AppLocalizations class.

We currently support multiple locales (e.g. English, German, Russian), and more can be
added by adding new ARB files.

---

## Files and Structure

- pubspec.yaml
  - Declares flutter_localizations as a dependency.
  - Enables code generation with flutter: generate: true.

- l10n.yaml (project root)
  - Configures the l10n tool:

    ```yaml   
    arb-dir: lib/l10n   
    template-arb-file: app_en.arb   
    output-localization-file: app_localizations.dart   
    ```

- lib/l10n/app_en.arb
  - English strings (template locale).

- lib/l10n/app_de.arb
  - German strings.

- lib/l10n/app_ru.arb
  - Russian strings.

- lib/l10n/app_localizations.dart (generated)
  - Generated by flutter gen-l10n.
  - Contains the AppLocalizations class used in the UI layer.

## Example ARB Entries

### Titles

English (app_en.arb)

```json  
{   
  "@@locale": "en",   
  "appTitle": "Around Me",   
  "splashTitle": "Around Me",   
  "homeTitle": "Around Me",   
  "placesTitle": "{category} around me",   
  "@placesTitle": {   
    "description": "Title for the places list screen",   
    "placeholders": {   
      "category": {   
        "type": "String"   
      }   
    }   
  }   
}
```


German (app_de.arb)

```json   
{   
  "@@locale": "de",   
  "appTitle": "Around Me",   
  "splashTitle": "Around Me",   
  "homeTitle": "Around Me",   
  "placesTitle": "{category} in meiner Nähe",   
  "@placesTitle": {   
    "description": "Titel für die Liste der Orte",   
    "placeholders": {   
      "category": {   
        "type": "String"   
      }   
    }   
  }   
}
```


Russian (app_ru.arb)

```json   
{   
  "@@locale": "ru",   
  "appTitle": "Around Me",   
  "splashTitle": "Around Me",   
  "homeTitle": "Around Me",   
  "placesTitle": "{category} рядом",   
  "@placesTitle": {   
    "description": "Заголовок экрана списка мест",   
    "placeholders": {   
      "category": {   
        "type": "String"   
      }   
    }   
  }   
}
```

After modifying ARB files, run:

```bash   
    flutter gen-l10n   
```

to regenerate app_localizations.dart.

## Using Localizations in Code

### main.dart

MaterialApp is configured with localization delegates and supported locales, and uses
a localized title:

```dart   
onGenerateTitle: (context) =>   
    AppLocalizations.of(context)?.appTitle ?? AppStrings.appTitleFallback,
```

### Widgets (simple strings)

For simple strings (no parameters), we use AppLocalizations directly, with safe access:

```dart
final l10n = AppLocalizations.of(context);
final homeTitle = l10n?.homeTitle ?? AppStrings.homeTitleFallback;

/// Inside Scaffold:
Scaffold(
appBar: AppBar(title: Text(homeTitle)),
body: ...
);
```

### Widgets (parameterized strings)

For messages with placeholders (e.g. category name in the places screen), we:

1. Define placeholders in ARB ({category} with @placesTitle metadata).
2. Call the generated method with a positional argument:

```dart   
final l10n = AppLocalizations.of(context);   
final placesTitle = l10n?.placesTitle(categoryName)   
    ?? AppStrings.placesTitleFallback(categoryName);   
```

or, using a small wrapper:

```dart   
final title = context.strings.placesTitle(category: categoryName);   
```

where context.strings is a typed helper wrapping AppLocalizations.

## Adding a New Locale

1. Create a new ARB file in lib/l10n, e.g. app_es.arb for Spanish.
2. Copy keys from app_en.arb and translate the values.
3. Run flutter gen-l10n.
4. Add the new locale to supportedLocales in main.dart:

```dart   
const supportedLocales = [   
  Locale('en'),   
  Locale('de'),   
  Locale('ru'),   
  Locale('es'),   
];
```


The app will then use the appropriate localization based on the device’s locale (if supported).
